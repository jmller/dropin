# Documentation

`README.md` is the public starting point. This directory contains concise operating
and platform information for users and contributors.

- [`operator-guide.md`](operator-guide.md) — operation, recovery, upgrades, and
  uninstall
- [`macos-validation.md`](macos-validation.md) — supported macOS scope and known
  limitations

Internal design notes, release checklists, review records, and development plans are
kept outside this public source tree. The repository source, tests, and CI are the
authoritative implementation references.
